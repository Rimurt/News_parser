# 📰 News Parser

Проект **News Parser** — это учебное приложение, разработанное для практики и закрепления навыков работы с парсингом веб-страниц, обработкой данных и автоматизации сбора информации.

## 📌 Описание проекта

Данный проект представляет собой парсер новостного сайта, который автоматически получает актуальные новости, извлекает необходимую информацию и структурирует её для дальнейшего использования.

Проект был создан в рамках самостоятельной практики для развития навыков:

- работы с HTTP-запросами  
- парсинга HTML-страниц  
- обработки и структурирования данных  
- работы с библиотеками для веб-скрейпинга  
- построения понятной структуры проекта  

---

## ⚙️ Основной функционал

- 📥 Отправка запроса к новостному ресурсу  
- 🔎 Поиск и извлечение блоков с новостями  
- 📰 Получение заголовков статей  
- 📝 Извлечение основного текста новости  
- 🕒 Получение даты публикации (при наличии на странице)  
- 🔗 Извлечение ссылок на полные версии статей  
- 📦 Сохранение полученных данных в базу данных 
- ⚠️ Базовая обработка возможных ошибок при запросах

## Цель проекта

Основная цель проекта — практическое освоение инструментов веб-парсинга, понимание структуры HTML-документов и получение опыта работы с реальными данными.
